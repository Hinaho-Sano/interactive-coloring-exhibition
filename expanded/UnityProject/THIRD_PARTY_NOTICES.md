# Third-party dependencies

Dependency binaries are not bundled in the public archive. Obtain them from their original publishers and review their applicable licenses.

| Dependency | Source / terms |
|---|---|
| Azure Kinect Sensor SDK 1.4.2 and depth engine | https://github.com/microsoft/Azure-Kinect-Sensor-SDK ; installed SDK LICENSE.txt and depth engine terms |
| MediaPipe Unity Plugin 0.16.3 | https://github.com/homuler/MediaPipeUnityPlugin ; MIT and bundled third-party notices |
| MediaPipe Hand Landmarker model | https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker ; publisher model terms and notices |
| System.Buffers, System.Memory, System.Runtime.CompilerServices.Unsafe, System.Reflection.Emit.Lightweight | Official Microsoft NuGet packages; package license metadata/files |
| Unity | https://unity.com/legal ; Unity is installed separately |

The gallery images and animal sprite sheets were generated for this prototype using the built-in imagegen tool. Prompts are included in ART_PROMPTS.txt. No franchise-specific character assets or logos are bundled.
