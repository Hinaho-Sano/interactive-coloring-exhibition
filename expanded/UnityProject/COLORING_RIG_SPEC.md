# 塗り絵キャラクター・リグ仕様

## 方針

完成済みイラストのコマを塗り絵と切り替える方式は使わない。四隅のマーカーで補正した塗り絵を、固定テンプレートと同じ座標のテクスチャとして読み込み、テンプレートごとに用意した2Dリグへ貼る。動いても子供が塗った色と線は変わらない。

既存のフクロウ・キツネのアニメーションは、羽ばたきや跳ね方のタイミングを決める参考にだけ使う。完成絵のピクセルは表示しない。

## テンプレート共通条件

- A4横、四隅のArUcoマーカー位置は現在の撮影パイプラインを維持する。
- 動物は横向きの基準姿勢に統一する。
- 印刷用は白背景、黒い輪郭だけ。影、光彩、グレー背景を入れない。
- 首、脚、翼、尻尾の付け根は、毛並みや羽の重なりで分割線を隠せる形にする。
- 動物領域の位置と大きさを全用紙で固定し、補正後の画像座標とリグのUVを一致させる。
- 左右反転は部位ごとではなく、完成したリグ全体に一度だけ掛ける。

## 部位

### ネコ

1. 胴体
2. 頭
3. 尻尾の根元
4. 尻尾の先
5. 手前の前脚
6. 奥の前脚
7. 手前の後脚
8. 奥の後脚

動きは、待機時の呼吸、歩行時の脚と胴体の上下、撫でた時の頭寄せ、猫じゃらし時の頭・前脚・尻尾の連動を用意する。

### イヌ

ネコと同じ基本構造に耳2枚を追加する。走行、撫で、尻尾振り、投げた物への反応を骨アニメーションで作る。

### トリ

胴体、頭、手前の翼、奥の翼、尾羽、脚2本に分ける。飛行時は翼を別角度で動かし、止まった時は羽を畳む。

## Unityへの取り込み

1. 撮影画像をマーカーで台形補正する。
2. テンプレート領域から背景を除去し、塗り絵テクスチャを生成する。
3. 種類ID（cat / dog / bird）を一緒に渡す。
4. 種類ごとのマスクとボーン設定を読み込む。
5. 同じ塗り絵テクスチャを全パーツのUVへ貼る。
6. Follow / Pet / Tease / Rest / Return の各状態でボーン角度だけを変える。
7. 進行方向が変わった時はリグ全体を左右反転する。

## 実装順

1. ネコの印刷用テンプレートを確定する。（完了: `cat_v2`）
2. ネコの8部位とピボットを定義する。（完了: `ColoringRigCatalog.CatV2`）
3. 実際に塗った `cat_v2` の撮影画像を使い、8部位マスクの境界を調整する。
4. 待機・歩行・撫で・猫じゃらしの4モーションを作る。
5. 撮影画像で色がずれないか確認する。
6. 同じ仕組みをイヌとトリへ展開する。

## cat_v2 の確定事項

- 補正後サイズ: 1160 x 700 px
- 原画の向き: 右向き
- 印刷物: `storybook_cat_coloring_template_v1.pdf`
- 撮影パイプライン: `--template cat_v2`
- 全体マスクと基準画像は `ImagePipeline/template/cat_v2` に配置済み
- Unity側の基準画像は `Resources/ColoringTemplates/CatTemplate.png`
